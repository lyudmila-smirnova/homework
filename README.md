# Проект "client-operation"

## Описание:

Проект "client-operation" - это программа на Python для управления базой данных клиентов и обеспечению безопасности счетов и карт клиентов.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:lyudmila-smirnova/homework.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте проект.
2. Запустите модули в папке src.
