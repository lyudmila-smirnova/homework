# Проект "client-operation"

## Описание:

Проект "client-operation" - это программа на Python для управления базой данных клиентов и обеспечению безопасности счетов и карт клиентов.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:lyudmila-smirnova/homework.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте проект.
2. Запустите модули в папке src.

## Тестирование:

### Запуск тестов:

Все тесты - pytest

### Структура тестов:

tests/
├── conftest.py  # Фикстуры с тестовыми данными
├── test_processing.py # Тесты модуля обработки данных
├── test_masks.py # Тесты масок карт/счетов
├── test_widget.py # Тесты виджетов
└── test_generators.py # Тесты функций-генераторов

### Тестируемые модули

1. Маскирование данных (masks.py):
1.1. Генерация масок для номеров карт (get_mask_card_number())
1.2. Маскирование номеров счетов (get_mask_account())

2. Виджеты (widget.py):
2.1. Форматирование дат (get_date())
2.2. Маскирование карт/счетов (mask_account_card())

3. Обработка данных (processing.py):
3.1. Фильтрация операций по статусу (filter_by_state())
3.2. Сортировка операций по дате (sort_by_date())

4. Генераторы (generators.py):
4.1. Фильтрация транзакций (filter_by_currency())
4.2. Определение типа перевода (transaction_descriptions())
4.3. Генерирование номеров карт и вывод в определенном формате (card_number_generator())
